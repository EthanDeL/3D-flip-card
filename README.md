# GSAP 3D Flip Card

An interactive 3D Flip Card animation built with Vue 3, GSAP, and ScrollTrigger. This project demonstrates how to create a smooth scroll-driven card animation featuring scaling, 3D rotation, and a modern UI, making it a great inspiration for landing pages, portfolios, or creative web experiences.

<img width="1376" height="896" alt="preview_3D-flip-card" src="https://github.com/user-attachments/assets/ab7ec215-a58b-44fd-ad65-e460284fd743" />

## Features

- **🎴 3D Flip Animation**: Smooth front-to-back card rotation powered by GSAP.
- **🚀 Scroll-Driven Experience**: Animation synchronized with the user's scroll using ScrollTrigger.
- **📌 Pinned Section**: Keeps the card centered during the animation for a cinematic effect.
- **✨ Modern UI**: Clean design with realistic depth and perspective.

## Technologies Used

- **Vue 3**
- **GSAP**
- **ScrollTrigger**
- **HTML5**
- **CSS3**

## Installation

**Clone the repository:**
```
git clone https://github.com/EthanDeL/3D-flip-card.git
```
Install dependencies:
```
npm install
```
Start the development server:
```
npm run dev
```

## Project Highlights

This project showcases several animation techniques, including:

Scaling the card before the flip animation.
3D transformations using rotateY and rotationX.
Perspective and preserve-3d for realistic depth.
Scroll-linked animations with scrub.
Pinned sections using ScrollTrigger.
